# 个人网站 · 从零到上线

这个文件夹里就是你的完整网站。**不需要装任何软件,不需要命令行,全部鼠标操作,大约 10 分钟上线。**

---

## 第 0 步:先看看长什么样(30 秒)

双击 `index.html`,会用浏览器打开。

- 右上角月亮/太阳按钮 → 切换深色 / 浅色
- 点导航栏的"作品""相册" → 平滑滚动
- 点相册里的照片 → 全屏放大,按 `Esc` 关闭
- 把浏览器窗口拖窄 → 自动变手机版布局

现在里面全是**占位内容**(灰蓝色渐变图 + "你的名字")。满意结构之后,按下面把它换成你自己的。

---

## 第 1 步:换成你自己的内容(最重要的一步)

**只需要改两个文件,其他一律不要动。**

### ① 打开 `content.js` —— 所有文字都在这里

用记事本打开就行(右键 → 打开方式 → 记事本)。里面每一项都有中文注释,照着改:

| 要改什么 | 找哪一行 |
|---|---|
| 姓名 | `name:` |
| 职业 / 身份 | `role:` |
| 一句话简介 | `tagline:` |
| 关于我的两段话 | `aboutP1:` `aboutP2:` |
| 技能 | `skills:` |
| 作品 | `works:` |
| 照片说明 | `gallery:` |
| 邮箱 | `email:` |
| GitHub / 微博等链接 | `links:` |

> ⚠️ **只改引号里面的字**,别删掉引号和行末的逗号。
> 中文引号 `“”` 不行,必须用英文引号 `""`。

### ② 换照片 —— 不用改代码,覆盖同名文件即可

打开 `images` 文件夹,把你的照片**改成下面的文件名**,覆盖掉原来的:

| 文件名 | 用在哪 | 建议尺寸 |
|---|---|---|
| `avatar.jpg` | 首屏头像(方形裁切) | 800 × 800 |
| `photo-1.jpg` ~ `photo-4.jpg` | 相册 4 张 | 1200 × 800 |
| `work-1.jpg` ~ `work-3.jpg` | 作品配图 3 张 | 1200 × 750 |

改完刷新浏览器就能看到。

> 想让照片更多?在 `content.js` 的 `gallery` 里复制一行 `{ src: "./images/photo-5.jpg", caption: "说明" },`
> 作品同理,复制 `works` 里一整个 `{ ... }` 块。

---

## 第 2 步:注册 GitHub(已有账号跳到第 3 步)

1. 打开 https://github.com/signup
2. 填邮箱 → 设密码 → 起用户名
3. **记住你的用户名**(英文/数字,比如 `zhangsan`),后面网址要用

---

## 第 3 步:建一个仓库

1. 打开 https://github.com/new
2. **Repository name** 填 `my-site`(或者你喜欢的任何名字,建议全小写)
3. 选 **Public**(必须是公开,免费版才能用 Pages)
4. **不要**勾选 "Add a README file"
5. 点绿色按钮 **Create repository**

---

## 第 4 步:把网站传上去(拖拽,不用命令行)

创建完会看到一个空仓库页面,上面有一行字:*"…or upload an existing file"*。

1. 点 **uploading an existing file**(或页面上的 **Add file → Upload files**)
2. 打开 `C:\Users\Administrator\Desktop\pweb` 这个文件夹
3. **全选里面的所有东西**(`Ctrl+A`),**整个拖进**网页中间那个虚线框
   - 包括 `images` 文件夹、`script.js`、`content.js` 等等,全都要
   - ⚠️ 有一个隐藏的 `.github` 文件夹也在里面,一起拖进去(它是自动部署用的)
   - 如果系统没显示隐藏文件:在文件夹顶部点 **查看 → 显示 → 隐藏的项目**,就能看到 `.github`
4. 等进度条走完(大概几秒到十几秒)
5. 页面往下拉,点绿色按钮 **Commit changes**

> **如果拖拽上传失败或太慢**:在文件资源管理器里选中所有文件 → 右键 → **发送到 → 压缩(zipped)文件夹**,
> 然后把这个 zip 拖进上传区,GitHub 会自动解压。

---

## 第 5 步:开启自动部署(点三次鼠标)

1. 在仓库页面点 **Settings**(顶部横排菜单最右边)
2. 左侧栏往下找到 **Pages**
3. **Build and deployment** 下面的 **Source** 下拉框,从 `Deploy from a branch` 改成 **`GitHub Actions`**
4. 改完不用点保存,它自动生效

---

## 第 6 步:等 1~2 分钟,拿你的网址

1. 点仓库顶部的 **Actions** 标签
2. 会看到一个叫 **Deploy to GitHub Pages** 的任务在转圈
3. 等它变成**绿色对勾**(通常 40 秒到 2 分钟)
4. 回到 **Settings → Pages**,最上面会显示:

   > Your site is live at **https://你的用户名.github.io/my-site/**

5. 点那个链接 —— 你的网站上线了 🎉

> 第一次打开如果显示 404,等 1 分钟再刷新。首次部署需要一点时间。

---

## 以后怎么改内容?

改完 `content.js` 或换了照片后:

1. 回到你的仓库页
2. 点 **Add file → Upload files**
3. 把改过的文件拖进去(覆盖同名文件)
4. 点 **Commit changes**

**就这一步。** 剩下的事 GitHub Actions 会自动做:1~2 分钟后网站自动更新,你不用点任何部署按钮。

---

## 想要更短的网址?

如果你把仓库名起成 **`你的用户名.github.io`**(比如 `zhangsan.github.io`),网址就会变成
`https://zhangsan.github.io/` —— 最短的形式。

步骤完全一样,只是第 3 步的仓库名换一下。

---

## 出问题了?

| 现象 | 原因和解决 |
|---|---|
| 打开是白屏 / 样式全丢 | 说明 `styles.css` 或 `script.js` 没传上去。回仓库首页看看这几个文件在不在根目录 |
| 照片不显示 | `images` 文件夹没传上去,或文件名大小写不对(`Avatar.JPG` ≠ `avatar.jpg`) |
| 页面文字变成了"你的名字" | `content.js` 没上传成功,或者你改完没保存 |
| Actions 有红色叉 | 点进去看日志。最常见原因是 **第 5 步的 Source 没改成 GitHub Actions** |
| 网址打开 404 | 等 1~2 分钟;还不行就确认仓库是 **Public** |
| 改了内容网站没变化 | Actions 还在跑,去 Actions 标签看是不是绿的;另外强制刷新一下浏览器(`Ctrl+F5`) |

## 文件都是干嘛的

```
index.html                     页面骨架(不用改)
styles.css                     外观样式(想换配色改最上面的 --accent / --accent-2)
script.js                      把内容渲染到页面上(不用改)
content.js        ← 改这个      所有文字内容
images/           ← 换这个      所有照片
site.config.json               给你自己看的备忘,记录你的用户名和仓库名
robots.txt                     告诉搜索引擎可以收录(不用改)
.github/workflows/deploy.yml   GitHub 自动部署配置(不用改)
```

---

## 想改配色?

打开 `styles.css`,最上面几行:

```css
:root{
  --accent:   #6366f1;   /* 主色:靛蓝 */
  --accent-2: #22d3ee;   /* 辅色:青色 */
}
```

把这两个颜色换成你喜欢的十六进制色值,整站配色就变了。

## 附:关于 git 和 token

**你完全不需要用到它们。** 上面全程是网页拖拽,不需要安装 Git,也不需要生成任何 Personal Access Token。

如果以后你想用命令行 `git push` 来更新,那时候再装 Git 也不迟 —— 但拖拽上传对个人网站来说已经够用了。
